# Бизнес-метрики: локальный демонстрационный прогон

Это описательная статистика авторских ERP-сценариев, а не оценка на клиентах или итоговом test.

Выборка: **5 уникальных сообщений / 4 диалога**. Уточнение — отдельное сообщение внутри той же беседы. Повторная отправка с тем же request_id не учитывается второй раз.

| Наблюдение | Значение |
| --- | ---: |
| Полнота учёта расхода | полная |
| Сообщения без записи расхода | 0 |
| Вызовы модели в клиентском чате | 5 |
| Входные токены | 22 912.00 |
| Выходные токены | 855.00 |
| Всего токенов | 23 767.00 |
| Среднее на вызов | 4 753.40 |
| Фактическая оплата API | 0.00 USD |
| Среднее время генерации | 23.72 с |
| Медиана генерации | 24.05 с |
| Минимум / максимум генерации | 17.13 / 30.61 с |
| Ответ без передачи оператору | 2/5 (40%) |
| Сообщения с передачей оператору | 3/5 (60%) |
| Диалоги хотя бы с одной передачей | 2/4 (50%) |

Отсутствие передачи не означает подтверждённого решения. Повторная передача в одной беседе не создаёт второй диалог в знаменателе. Время — внутри generate: очередь, подготовка и доставка ответа не включены. Первый токен и p95 на этой малой выборке не заявляются.

Raw-решение модели о передаче: да 2, нет 2, нет валидного решения 1. Маршрут сервера считается отдельно: он учитывает бизнес-правила и резервную передачу при ошибке модели.

## Что пока не измерено

Подтверждённое решение проблемы, экономия времени оператора, человеческая исходная скорость, электроэнергия и полная себестоимость — **не измерены**. 0 USD означает отсутствие оплаты API; время GPU и электричество не объявляются бесплатными.
