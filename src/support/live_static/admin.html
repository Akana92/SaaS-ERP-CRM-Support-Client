Обращения и шаги

Один диалог. Две модели.

Каждый вопрос получают обе модели. Base и Fine-tuned продолжают свою переписку с учётом собственных публичных ответов. Сырые ответы доступны в каждом ходе. Версия адаптера сохраняется вместе с ответом; результат завершённого эксперимента — в разделе качества.

Примеры для демо-ERP

Все данные вымышленные. Укажите номер объекта один раз — уточнения в этой беседе относятся к нему. Для другой темы начните новый диалог; для другого объекта укажите новый номер.

Пример добавится в поле вопроса без отправки. Ваш черновик сохранится.

Base появится первой, затем Fine-tuned. Время каждого вызова учитывается.

Фактические расходы

Клиентские обращения и эксперименты учитываются отдельно. API на локальном запуске — $0; электричество и оборудование сюда не входят.

Требуется участие человека

Редактирование и одобрение сохраняются локально. Ответы клиентам не отправляются.
