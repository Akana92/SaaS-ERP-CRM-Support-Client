# Проверка Docker-поставки

19 сентября 2026: Windows / Docker Desktop WSL2 / RTX 3080 Laptop 16 ГБ. Engine 29.7.2, Compose 5.4.0; контейнер Python 3.11.11, PyTorch 2.6.0+cu124. Base и принятый адаптер F подключены из существующих локальных папок только для чтения.

| Проверка | Результат |
| --- | --- |
| Сборка образа, зависимости pip check | PASS |
| CUDA и библиотеки Transformers/PEFT/bitsandbytes | PASS |
| SHA-256 всех разрешённых Base/adapter файлов внутри контейнера | PASS |
| Клиент и админка HTTP | 200, quality-f, client_mode=fine_tuned |
| Две связанные реплики о вымышленном INV-1002 | Ответы получены, контекст счёта сохранён |
| Пересоздание контейнера | Та же беседа и два request_id сохранились |
| Сравнение Base/F | Завершено за 35,2 с; одинаковый вход, Base без адаптера, F с адаптером |
| Штатный stop и Docker Compose SIGTERM | exit 0; записан stopped, GPU 0 MiB после остановки |
| Windows технические тесты | 179 тестов: 170 PASS, 9 SKIP |
| Linux технические тесты | 179 тестов: 173 PASS, 6 SKIP; также повторены в чистом CI-venv, включает реальный SIGTERM subprocess |

Это smoke-проверка упаковки, а не новая оценка качества модели. Две реплики заняли около 23 и 18 секунд; эти значения не являются SLA. Проверен BF16, NF4 в контейнере отдельно не измерялся. Установка на другом ноутбуке не проверена.

Получение одного закреплённого публичного файла HF прошло с правильным SHA после повторов TLS. На этой машине Windows truststore решает проблему доверенных сертификатов; для иной сети могут потребоваться её доверенные CA. Проверку HTTPS не отключали. Полное скачивание Base в пустую папку внутри Docker не повторялось: проверены существующие веса. Загрузка собственных Model/Dataset пока заблокирована правами токена, их удалённые версии ещё не закреплены.
