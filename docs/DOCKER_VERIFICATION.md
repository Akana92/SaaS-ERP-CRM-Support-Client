| Клиент и админка HTTP | 200, quality-f, client_mode=fine_tuned |

Это smoke-проверка упаковки, а не новая оценка качества модели. Две реплики заняли около 23 и 18 секунд; эти значения не являются SLA. Проверен BF16, NF4 в контейнере отдельно не измерялся. Установка на другом ноутбуке не проверена.

Получение одного закреплённого публичного файла HF прошло с правильным SHA после повторов TLS. На этой машине Windows truststore решает проблему доверенных сертификатов; для иной сети могут потребоваться её доверенные CA. Проверку HTTPS не отключали. Полное скачивание Base в пустую папку внутри Docker не повторялось: проверены существующие веса. Собственные публичные Model/Dataset опубликованы 19 сентября 2026: Model `b0862d45d6a2bf71eb1578ac8ca91cdf6e5d5986` (12 файлов, 148 087 233 байта), Dataset `84813aabfdaf1b9f85f17955128d5003872b7554` (15 файлов, 2 650 126 байт); ревизии закреплены в `configs/asset-sources.json`. Полное повторное скачивание обеих закреплённых ревизий без токена выполнено: для всех 12 файлов Model и 15 файлов Dataset совпали размеры и SHA-256. Дополнительно штатный загрузчик внутри нового Linux-контейнера скачал все файлы адаптера и 13 TRAIN-шардов в пустые временные каталоги без токена и проверил их SHA-256. Docker bootstrap этих двух артефактов пройден; загрузка Base с нуля отдельно не повторялась.
