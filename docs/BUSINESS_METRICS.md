# Польза для бизнеса: метрики и границы

19 сентября 2026. Сейчас подтверждены локальная обработка обращений, маршрутизация и расход токенов. Экономия времени человека и результат на реальных клиентах ещё не измерены.

| Основная метрика | Формула и решение | Статус |
| --- | --- | --- |
| Подтверждённое решение без оператора | Подтверждённые пользователем/рецензентом решения без человека / все подходящие диалоги; определяет пригодность сценария к автоматизации | Не измерено. `answered` не является подтверждением решения. |
| Активное время оператора | Среднее время чтения, проверки и подготовки ответа без AI минус сопоставимое время с AI | Не измерено. Ожидание GPU не равно труду оператора. |
| Расход на обработку | Входные + выходные токены и фактическая оплата API на уникальный вызов/сообщение | Измерен на ручном прогоне; полная себестоимость неизвестна. |

Дополнительно наблюдаем передачи специалисту, невалидные ответы модели и время генерации. Ограничители — корректность решения и отсутствие раскрытия чужих фактов: увеличение автоматических ответов при росте ошибок не считается улучшением. SLA и новые целевые проценты по малой выборке не назначались.

## Что уже посчитано

[Отчёт](../reports/business-metrics.md) и [JSON](../reports/business-metrics.json) получены из **5 уникальных сообщений / 4 вымышленных диалогов**. Одно сообщение — уточнение в прежней беседе. Выборка намеренно содержит ошибку модели и попытку доступа к чужому объекту; это проверка функций, не случайный клиентский поток.

- **23 767 токенов**: 22 912 входных и 855 выходных; в среднем **4 753,4 на вызов**. Вход включает правила и историю, а не только текст клиента.
- Фактическая оплата API — **0 USD**. Электричество, амортизация и полная стоимость обращения не измерялись.
- Генерация: среднее **23,72 с**, медиана **24,05 с**, диапазон **17,13–30,61 с**. Очередь, подготовка и доставка не входят; это не время до первого токена.
- Без оператора ответили **2/5 сообщений**; передано **3/5 сообщений**. Передача была в **2/4 диалогов**. Не называть 40% доказанной долей успешной автоматизации.
- Raw-модель: передача «да» в двух ответах, «нет» в двух, один результат невалиден. Решение сервера учитывается отдельно.
- Пара Base/F — ещё **9 425 токенов**, **0 USD**, **33,949 с** суммарной генерации. Эти два вызова исключены из клиентских знаменателей.

F49/Base10 из [исследования](CANDIDATE_F_RESULTS.md) относятся к синтетическому development и NF4, а не к бизнес-эффекту BF16-сервера. Закрытый итоговый test и человеческая оценка не добавлялись.

## Как измерить реальную экономию

1. Подготовить отдельные разрешённые вымышленные задачи по счетам, SIM и доступам одинаковой сложности. Не использовать закрытые вопросы курса и не отправлять наблюдения в обучение.
2. Случайно распределить сопоставимые задания между «без AI» и «с AI». Избегать немедленного повторения одной задачи тем же человеком: запоминание искажает результат.
3. Отдельно засекать активную работу и полное ожидание. Заполнить [CSV](../reports/operator-time-study-template.csv): `mode` = `without_ai` / `with_ai`, время в секундах, `resolved`, `correctness_reviewed`. Использовать псевдонимы, без персональных и платёжных данных.
4. Проверить корректность и факт решения. Исправления и неудачные ответы тоже включать в время. Сравнить режимы внутри одинаковых семейств задач, указав объём и разброс.

Экономия = среднее активное время без AI − среднее с AI. Отрицательные значения не отбрасываются. Процент считается только при положительном измеренном baseline. Малый учебный пилот не доказывает эффект на реальном потоке обращений.

CSV сейчас содержит только заголовок — выдуманных наблюдений нет. Пересборка отчёта не затирает заполненный файл.

## Воспроизводимость

`python scripts/build_business_report.py` рассчитывает показатели из `artifacts/stage5/latency-2026-09-19/http/http-smoke.json`. Source SHA записан в отчёте. Повторы request/call ID не начисляются дважды; конфликтующие дубликаты отклоняются; неизвестные расходы не превращаются в нули. Unit-тесты проверяют эти границы.

Лёгкий комплект содержит агрегаты и тесты формул, без переписки. Исходный авторский smoke остаётся в workspace; для независимой пересборки его можно передать отдельно после проверки состава. Доступ к нему не даёт доступа к закрытому test.
