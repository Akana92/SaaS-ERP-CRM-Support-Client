# AI Customer Support Manager

Локальный учебный прототип русскоязычной поддержки SaaS с вымышленной ERP: счета, SIM и доступы. Клиентский чат показывает ответ и четыре метки; администратор видит Base/Fine-tuned, историю, маршрутизацию, токены и время.

Это **лёгкий комплект для локальной проверки**, без весов, полного корпуса, checkpoints и пользовательской переписки. Открытая публикация и выбор лицензии собственного кода/данных ещё не выполнены; коммерческая готовность не заявляется.

Стек: Python 3.11, PyTorch, Transformers/PEFT, Qwen3 4B + адаптер F, LangGraph, FastAPI и HTML/CSS/JavaScript. Платный API и облачный tracing не используются. Проверено на Windows / RTX 3080 Laptop 16 GB.

После подготовки окружения и отдельных весов из корня:

```powershell
.\.venv\Scripts\python.exe -X utf8 -B scripts/live_demo.py start
```

Дождаться `/health` с `loaded: true`. [Клиент](http://127.0.0.1:7860/client/) · [Админка](http://127.0.0.1:7860/admin/). Завершение — `scripts/live_demo.py stop`, затем дождаться фактического `stopped`.

**F49/100 против Base10/100** — описательная AI-оценка синтетического development/NF4, QUALIFIED; человеческого подтверждения и итогового закрытого test нет. Live работает в BF16. Ручные ответы занимали **17–31 с**, пара Base/F около **34 с**; это малые выборки, не SLA.

Внутри архива `MANIFEST.json` перечисляет файлы, SHA и отдельно необходимые модели. Чистая установка на другом компьютере ещё не проверена. Архив ориентирован на демонстрацию продукта; полный исторический training/evaluation workspace и корпус передаются отдельно.
